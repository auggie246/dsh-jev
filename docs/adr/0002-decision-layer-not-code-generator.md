# Jev is a decision layer, never a code generator

Jev returns typed Choice/Noul/Score answers with probabilities and cannot write code or hold a conversation; TypeSafe's own coding-agents guidance says it is not a drop-in replacement for the model behind a coding harness. DeepSeek stays the only model that generates text and code. The plugin only gates, routes, verifies and suggests, and no Recipe may depend on a Judge producing prose.
